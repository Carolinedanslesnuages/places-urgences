# Places urgences

**Objectif :** Aider la préfecture à retrouver rapidement où loger des personnes sinistrées lors d’une inondation ou d’une tempête.
**Type :** carte interactive (lieux sur fond IGN, liste accessible, filtres)
**Stack :** Vue 3, DSFR, MapLibre (modèle ADA `carte`)
**Lieux :** `src/donnees/lieux.json`
**Créé le :** 2026-11-23 par Carolinedanslesnuages

## Lancer le projet
| Action | Commande |
|---|---|
| Lancer | `npm run dev` |
